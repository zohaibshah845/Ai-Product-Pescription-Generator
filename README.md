# AI E-commerce Product Description Generator

A comprehensive AI-powered product description generator for e-commerce stores with user authentication, payment integration, analytics, team collaboration, Chrome extension, and Shopify integration.

## ✨ Features

- 🤖 **AI-Powered Generation** - Generate high-converting product descriptions
- 👤 **User Authentication** - Complete auth system with JWT tokens
- 💳 **Payment Integration** - Stripe subscription management
- 📊 **Analytics Dashboard** - Real-time usage analytics
- 👥 **Team Collaboration** - Work together with team members
- 🛍️ **Shopify Integration** - Sync products and descriptions
- 🔌 **Chrome Extension** - Generate descriptions from any webpage
- 🌍 **Multi-Language Support** - 15+ languages supported
- 🎨 **Multiple Tones** - Professional, casual, luxury, and more
- 📈 **SEO Optimized** - Built-in SEO best practices

## 🚀 Quick Start

### Prerequisites

- Python 3.8+
- Node.js 14+
- npm or yarn

### Backend Setup

```bash
cd backend
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt

# Edit .env with your configuration
python run.py
